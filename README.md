# ⚡ Cyber Runner 3D: Neon Overdrive

High-speed retro-futuristic synthwave 3D endless runner built with Three.js and Web Audio API.

![Gameplay Preview](preview.png)

## 🎮 How to Play
- **A / D** or **◀ / ▶**: Switch lanes (left / right)
- **Space** or **▲**: Jump
- **Shift**: Nitro Hyperdrive Boost (220+ km/h)
- **Touch / Mobile**: Virtual controls on the bottom of the screen
